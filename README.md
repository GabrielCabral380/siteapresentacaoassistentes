Este é o site de apresentação dos assistentes **Xavier**, **Maya** e **Gabriel**.

## Como Colocar no Ar (GitHub Pages)

Para corrigir ou ativar o site no GitHub Pages, siga estes passos:

1.  **Crie o Repositório:** Crie um novo repositório no GitHub chamado `siteapresentacaoassistentes` (ou o nome que preferir).
2.  **Envie os Arquivos:** Suba todo o conteúdo desta pasta para o repositório criado.
3.  **Configure o Pages:**
    *   No GitHub, vá em **Settings** > **Pages**.
    *   Em **Source**, selecione **Deploy from a branch**.
    *   Escolha o branch `main` (ou `master`) e a pasta `/(root)`.
    *   Clique em **Save**.

Após alguns instantes, o site estará disponível no endereço fornecido pelo GitHub. Se houver erro 404, verifique se o arquivo `index.html` está na raiz do repositório.
